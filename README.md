# QAZCLINKER — новая главная

Вёрстка новой главной страницы поверх существующей стилевой системы сайта.
Открывается локально: `index.html`, сборка не нужна.

## Как разложены файлы

Всё поделено на **existing** — то, что уже есть на боевом сайте, и **new** —
то, что появилось для этой страницы.

```
index.html               разметка страницы целиком

css/existing/            копии боевых файлов, ПЕРЕНОСИТЬ НЕ НУЖНО
  style.css              /local/templates/qazclincker/css/style.css
  normalize.css
  swiper-bundle.min.css
css/new-index.css        НАШИ стили — дописать в конец боевого style.css
css/fonts.css            только для локального просмотра, в шаблон НЕ переносим

js/existing/             копии боевых скриптов, ПЕРЕНОСИТЬ НЕ НУЖНО
  main.js  swipers.js  imask.js  swiper-bundle.min.js
js/new-index.js          НАШИ скрипты — дописать в конец боевого main.js

img/existing/            уже лежит на сервере в src/, заливать не нужно
  footer-bg.svg          src/icons/footer-bg.svg
  video/hero.mp4         src/videos/0116.mp4
img/new/                 НОВЫЕ картинки — залить в src/images/

fonts/existing/          TT Firs Neue, на сайте уже подключён
fonts/new/Steelfish/     НОВЫЙ шрифт — положить в src/fonts/
```

## Что нужно сделать при натяжке

1. Разметку из `index.html` разложить по `index.php`, `header.php`, `footer.php`.
2. `css/new-index.css` дописать в конец боевого `css/style.css`.
3. `js/new-index.js` дописать в конец боевого `js/main.js`.
4. Картинки из `img/new/` залить в `src/images/`, поправить пути.
5. Шрифт `fonts/new/Steelfish/` положить в `src/fonts/` и подключить его `stylesheet.css`.
6. Пути к видео и фону футера вернуть на `/local/templates/qazclincker/src/...` —
   эти файлы на сервере уже есть, здесь они лежат локально только ради превью.
7. Блок новостей вывести компонентом `bitrix:news.list` (шаблон `news-main-list`),
   сейчас восемь карточек зашиты в разметку.
8. Подсветку активного пункта меню перевести на `$APPLICATION->GetCurPage()`
   вместо JS — см. начало `js/new-index.js`.

## Чего не хватает

- **`ajax/forms/samples_form.php`** — форма заказа образцов шлёт туда POST,
  файла на бэке нет. Модалка работает, она на боевом `call_form.php`.
- **7 страниц** — История, Руководство, Вакансии, Контакты, Застройщикам,
  Дополнительные услуги, Производители. В разметке помечены `<!-- НЕТ СТРАНИЦЫ -->`.
- **PDF каталога** для кнопок «Скачать каталог».
- **Контакты** — в макете рыба (российский индекс и код города), сейчас стоят
  боевые значения с сайта.
- **Лицензия на Steelfish** — в архиве идёт Desktop-лицензия, веб-встраивание
  она не покрывает.

## Договорённости по вёрстке

- Все размеры — `calc(N * var(--width-multiplier))`, где N — число из макета.
- Один брейкпоинт: `@media (max-width: 768px)`.
- Цвета только переменными, палитра в начале `css/new-index.css`.
- Отступы между блоками: 140 на десктопе и 100 на мобилке,
  половина сверху и половина снизу у каждой секции.
- Фаска углов — `clip-path` через `--cut` / `--mid`, как на остальном сайте.
- Отступы меню взяты боевые, а не из макета — по макету оно не помещалось в экран.
- Мобильных макетов не было, мобильная версия сделана по здравому смыслу.
